# Steal a Brainrot — Xeno

Скрипт для [основного Steal a Brainrot](https://www.roblox.com/games/109983668079237/Steal-a-Brainrot). Совместимость с Duel Server сохранена.

Вставь в Xeno:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/v9ysen-sketch/brainrot-duel-xeno/main/brainrot_xeno.lua"))()
```

- **F6** — автозахват и доставка на собственную базу.
- **F7** — возврат к базе; при переносе предмета пытается завершить доставку.
- **Right Ctrl** — скрыть или вернуть панель.
- **Mark base** — указать площадку вручную, стоя на ней, если игра не показывает владельца участка.
- **Speed** — ускорение и измерение фактической скорости; статус `limited`/`corrected` показывает, что сервер ограничил движение.
- **Diag** — вывести сведения об участке, переносе, скорости и снаряжении в консоль; при доступном `setclipboard` также копирует JSON.

Для мгновенного возврата в основном режиме нужен принятый игрой способ перемещения: заранее поставленный **Quantum Cloner** у своей площадки или уже экипированный **Flying Carpet**. Если сервер отклоняет перемещение, скрипт идёт к базе маршрутом. Статус `confirmed` ставится только после завершения переноса и изменения списка животных на своей базе.
